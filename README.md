# Jogo-da-velha
Descrição: Esse jogo da velha foi desenvolvido com o intuito focado totalmente em exercitar e reforçar minha lógica de programação. Para isso utilizei a linguagem C, basicamente por puro interesse nesta.

Funcionalidades:
-`Escolha de qual jogador inicia a rodada`: a primeira coisa que acontece ao iniciar o jogo é ser questionado sobre qual jogador começará a rodada, X ou O;
-`Exibição de quem é o lance`: cada vez conta com a exibição de qual jogador será
-`Não permitido selecionar um quadrado já ocupado`: não permite que um jogador sobreponha o quadrado já ocupado por ele mesmo ou seu adversário
-`Opção de jogar de novo`: após o fim de cada partida, seja por vitória ou empate, é possível iniciar uma nova rodada.
-`Exibição dos pontos`: ao fim de cada rodada é demonstrado o placar de vitórias, respectivamente do jogador X e do jogador O.
